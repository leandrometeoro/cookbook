# Cookbook do Leandro

Receitas técnicas por assunto, publicadas em
**<https://leandrometeoro.github.io/cookbook/>**.

- Conteúdo em `docs/<assunto>/<receita>.md` (Markdown puro)
- Site gerado com [MkDocs Material](https://squidfunk.github.io/mkdocs-material/)
- Deploy automático a cada push na `main` (GitHub Actions → branch `gh-pages`)

Preview local (opcional):

```bash
pip install mkdocs-material
mkdocs serve   # http://127.0.0.1:8000
```
